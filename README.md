# Mobile Showcase with Tailwind CSS

A responsive product showcase page built with Tailwind CSS v4 and Vite.

The project includes:
- A responsive top navigation with a mobile menu toggle
- A left sidebar with a login form and useful links
- A product card grid with hover interactions
- Light and dark mode styles
- Static assets served from the public folder

## Tech Stack

- Vite
- Tailwind CSS v4
- HTML5
- CSS

## Project Structure

- index.html: Main page markup and layout
- src/style.css: Tailwind import and global CSS rules
- public/: Static images and assets used by the cards
- vite.config.js: Vite config with Tailwind plugin

## Getting Started

### 1) Install dependencies

npm install

### 2) Start development server

npm run start

### 3) Build for production

npm run build

### 4) Preview production build

npm run preview

## Notes

- The HTML lang attribute is currently set to Spanish.
- Tailwind is loaded from src/style.css using the Tailwind CSS v4 import.
- Vite is configured to use the Tailwind Vite plugin.
